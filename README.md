# SIGMA GROUP — B2B Platform Starter

واجهة أولية عربية RTL لمنصة سيجما جروب للمشتريات والمنتجات والخامات الدوائية في مصر.

## ما الموجود حالياً؟
- صفحة رئيسية تجريبية لمساحة العميل.
- تصميم عربي RTL ومتجاوب مع الهاتف والكمبيوتر.
- أقسام مختصرة للسوق والطلبات والفواتير والحساب المالي.
- بيانات توضيحية فقط؛ لا توجد قاعدة بيانات أو عمليات دفع حقيقية في هذه المرحلة.

## المتطلبات
- Node.js 20.9 أو أحدث
- npm

## التشغيل محلياً
```bash
npm install
npm run dev
```
ثم افتح:
http://localhost:3000

## الخطوات التالية
1. بناء صفحات السوق وتفاصيل المنتج والسلة.
2. إضافة تسجيل الدخول وتسجيل الشركات ومراجعة الحسابات.
3. إعداد Supabase/PostgreSQL مع سياسات RLS.
4. بناء الطلبات والفواتير وسجل الحساب والمدفوعات.
5. إضافة إدارة المخزون والدفعات والصلاحية.
6. الاختبار الأمني والتشغيلي قبل أي استخدام حقيقي.

> تنبيه: هذا Starter UI وليس نظاماً محاسبياً أو دوائياً جاهزاً للإنتاج. يجب اعتماد البيانات والإجراءات والامتثال التنظيمي قبل التشغيل التجاري.
